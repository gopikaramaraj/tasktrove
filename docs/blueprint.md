# **App Name**: TaskTrove

## Core Features:

- Authentication: User authentication with email/password and Google OAuth using Firebase.
- Community Management: Create and join public/private communities, manage member requests.
- Challenge & Habit Tracking: Create and track challenges and habits within communities.
- Gamification System: Gamified experience with XP, badges, and streaks.
- Leaderboards: Display public and private leaderboards within communities.
- Live Check-ins: Enable live video check-ins using free WebRTC tools for challenges.
- AI-Powered Suggestions: Suggest personalized challenges and habits based on user activity and community trends. The LLM will use a tool to determine when or if user preferences align with current suggestions.

## Style Guidelines:

- Primary color: Royal gold (#FFD700) to convey prestige, success, and a sense of reward, linking to the gamified aspects.
- Background color: Cream / Off-white (#FAF9F6), creating a soft, welcoming, and modern feel.
- Accent color: Amber (#FFBF00) for interactive elements and highlights, drawing attention and adding warmth.
- Font pairing: 'Poppins' (sans-serif) for headings and 'PT Sans' (sans-serif) for body text. This combination provides a balance of modern clarity and readability.
- Use minimalist, line-based icons to represent challenges, habits, and community activities. Icons should be in the royal gold (#FFD700) to maintain visual consistency.
- Employ a clean and organized layout with a focus on visual hierarchy. Utilize cards and grids to display communities, challenges, and user progress.
- Subtle animations for achievements and streak milestones to provide positive feedback and a sense of accomplishment.
